Flutter Weather App

A simple and responsive weather application built using **Flutter and Dart**, providing real-time weather information through REST API integration.

## Features
- Real-time weather updates
- Current location weather
- Search weather by city
- Temperature, humidity, and wind speed
- Weather condition icons
- Location permission handling
- Local caching and error handling

Technologies
- Flutter & Dart
- REST API
- Geolocation
- SharedPreferences

 Getting Started

```bash
git clone https://github.com/Hardy0004/WeatherApp.git
cd flutter-weather-app
flutter pub get
flutter run
```

Configure your weather API key before running the application.
